# Literature review

Libor “Burny” Burian · November 19, 2026

**Question.** When several agents can read the same folder, does splitting the question among independent investigators improve the answer under a shared budget? Two mechanisms can compete. Independent searches can uncover complementary facts. Summarizing and merging their findings can lose qualifiers or reward a majority that all read the same misleading passage.

| Evidence | Design and relevant finding | Consequence for this study |
|---|---|---|
| [ArcticSwarm](https://arxiv.org/html/2609.01870v2) and [local-folder replication](https://github.com/BurnyCoder/arcticswarm-folder-rag-research/blob/bd5b3ed98cde10e9c1f90795f2182d84ecd51ddc/reports/experiments/day1-main-vs-single-agent.md) | Deferred consensus was developed for deep research. The local study used a different model, corpus and time budget. Its agent-count sweep measured caps and actual agents separately. | Count distinct agents, record actual completions, share the budget, and expose the single-agent counterpart. |
| [RISE](https://arxiv.org/html/2606.06880) and [MIT implementation](https://github.com/texttron/RISE) | A retriever builds a workspace an agent can inspect repeatedly. The authors report comparable accuracy at lower cost in one fixed-corpus setting. The size ablation does not indicate monotonic improvement. | Allow a reader to move from a search hit to its original context and test the effect of dense retrieval. |
| [Direct corpus interaction](https://arxiv.org/html/2605.05242) and [implementation](https://github.com/DCI-Agent/DCI-Agent-Lite) | Terminal search and file reads are a competitive retrieval mechanism in the authors' benchmarks. | Include actual Codex with the same mounted corpus and a terminal. |
| [Deep agentic versus semantic search](https://arxiv.org/html/2608.01507) | The authors found lower success for delegated grep than semantic search in their implementation and identified handoff failures. Their evaluation and backbones differ from this experiment. | Preserve concrete excerpts across the handoff and measure failures to assemble already-read facts. |
| [SWE-QA](https://aclanthology.org/2026.findings-acl.402/) and [DeepRepoQA](https://arxiv.org/html/2608.24221) | The former compares direct, retrieval and agent baselines. The latter evaluates structured repository exploration and verification. Both document variation across models and methods. | Use pinned repository revisions, identifier search, definitions and cross-file navigation. Reuse the released rubric and qualify conclusions from a same-family grader. |
| [MultiHop-RAG](https://arxiv.org/html/2401.15391v1), [released evaluator](https://github.com/yixuantt/MultiHop-RAG/blob/main/qa_evaluate.py) and [IRCoT](https://arxiv.org/html/2212.10509) | MultiHop-RAG separates null, temporal, comparison and inference queries and provides evidence facts. Interleaving retrieval with intermediate reasoning improved multi-step QA in IRCoT's settings. The published overlap script accepts shared tokens. | Preserve each stratum, separate short answers from explanations, and inspect which evidence reached each agent. |
| [Reciprocal rank fusion](https://cormack.uwaterloo.ca/cormacksigir09-rrf.pdf), [BM25S](https://github.com/xhluca/bm25s), [Qwen3 embeddings](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B) | Sparse scores and vector similarities have different scales. Rank fusion combines ranked lists without fitting score calibration on benchmark questions. | Use equal-weight reciprocal ranks with the published rank constant. Follow Qwen's instruction-prefixed query and unprefixed document convention. |
| [ALCE](https://aclanthology.org/2023.emnlp-main.398/) | Citation correctness and completeness concern support for claims. A valid file address alone does not measure either. | Verify quote delivery mechanically and audit entailment with a separate blinded prompt. |

The evaluation follows the [NeurIPS checklist](https://neurips.cc/public/guides/PaperChecklist) and [Lones's guide to ML pitfalls](https://arxiv.org/abs/2108.02497) for primary outcomes, partitioning, uncertainty and reproducibility. The method is a synthesis of existing components. The contribution to test is a paired, budgeted, cross-domain comparison with auditable handoffs.
