# Development amendments

On November 19, before scoring any fresh answers, we inspected the eight-agent trace for legacy question `mhr_0570`. The gateway recorded per-investigator limit refusals for workers that spent their last request on another tool call. Their histories contained evidence that never reached the coordinator.

The last allowed investigator request now disables tool selection and requests a final structured report from its current evidence. All affected multi-agent development conditions run under new unit identifiers. The initial attempts and their cost remain in the private ledger and the [pilot report](experiments/handoff-pilot.md). Development size selection uses only the revised runs. Single-agent and external baseline runs are reused. The [registered confirmatory analysis and resource ceilings](preregistration.md) apply.

The repository intervention copies the pinned Requests development checkout and edits the pool-size constant, following the default HTTPS adapter from Session creation to HTTPAdapter configuration. The pipeline checks the source precondition before writing the experimental copy. Evidence support judges inspect the entire proposed answer for uncited claims in addition to rating individual citations. The gold-news exposure judge runs separately.
