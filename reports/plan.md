# Execution plan

1. Register the scientific rationale, size-selection rule, paired evaluation, API limits and private release workflow.
2. Materialize immutable folders and split manifests. Build a bounded Codex execution environment, hybrid local index, evidence ledger, Arctic adapter, controls and metered gateway.
3. Test isolation, quotes, index invalidation, budgets, restart handling, scorers and the normal command without paid calls. Push a private source and artifact milestone.
4. Run the development size sweep, historical bridge and cost pilot. Freeze the selected size and number of balanced test blocks before opening held-out results.
5. Run paired confirmation and diagnostics, audit evidence, and regenerate all tables, dashboards, plots and the paper. Record milestones, limitations, and deviations in the experiment reports.

Use the checked-out project for source, a local uv environment, and a dedicated data directory for corpora, caches and timestamped logs. Maintain privacy for every release. [Preregistration](preregistration.md)

## Implementation and measurements

The private code and artifact releases include a single-folder CLI, independent isolated Codex sessions, shared cost reservations, local GPU retrieval, source validation and trace recording. Each swarm size counts its coordinator. All arms are tested with a scripted local Responses service before paid evaluation. Real-answer smoke tests cover a cross-file question and a missing date. The historical bridge and first investigator handoffs are in the [experiment summary](summary.md). The first development change and its selection rule are recorded in the [amendments](development-amendments.md).

The confirmatory phase retains an explicit comparison with the single-agent version of the same harness. The fixed control panel varies size again and measures closed-book, random, annotated news, lexical-only and verification-disabled conditions. The Requests intervention edits a default pool-size constant and asks how it propagates across files. Costs, times, literal quote verification, citation support, assertion coverage, gold exposure and investigator completion are reported separately.
